# キャンバス再整列とウィンドウ拡大 — Design

> Written by: Codex · Last updated: 2026-08-07
> Status: agreed
> Upstream: none — standalone run

## 目的

キャンバスで調整した枠の配置を、すでに起動中の通常ウィンドウへ適用できるようにする。あわせて、アクティブなウィンドウを作業状況に合う大きさ・位置へ拡大し、いつでも最初のタイル位置へ戻せるようにする。

## 操作仕様

- キャンバスの「起動」の直左に「並べ直す」を置く。現在のキャンバスセル（位置・幅・高さ）をそのまま起動済みウィンドウへ適用する。
- `Option+X` は選択済みの拡大サイズと、拡大直前のサイズを交互に切り替える。
- `Option+Z` は、そのウィンドウで拡大を始める前の最初のタイル位置・サイズへ一発で戻す。拡大中に手動でリサイズしても、復帰先は変更しない。
- 拡大サイズは「縦横半分」「横半分・縦いっぱい」「縦横3/4」「画面いっぱい」「縦だけいっぱい」「カスタム幅・高さ」から選ぶ。
- 拡大位置は「現在位置を中心に拡大」と「画面中央へ移動して拡大」から選ぶ。
- キー変更はChromeのショートカット設定ページへ遷移して行う。拡張から直接のキー再割当は行わない。

## 実装境界

- `background.js` がウィンドウの座標計算、履歴、Chromeコマンドを担当する。
- `src/components/SpotlightConfig.jsx` が設定の選択、カスタム値、ショートカット変更の入口を担当する。
- `src/App.jsx` と `src/components/WorkspaceCanvas.jsx` がキャンバス座標をバックグラウンドへ渡す。
- 履歴は `chrome.storage.session` に保存し、Service Worker の休止をまたいで復帰先を保つ。

## エラーと境界条件

- 対象となる通常ウィンドウがない場合は再整列しない。
- カスタム値は20〜100%に制限する。
- 最大化・フルスクリーン状態からの復帰は、状態を通常へ戻してから座標を適用する。
- Chromeショートカットの実際の割当表示は、利用可能な場合は `chrome.commands.getAll()` から読む。取得できない環境では既定表記を案内する。
