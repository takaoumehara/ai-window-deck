# デッキ対象の再整列・空き枠ドロップ・拡大プレビュー — Design

> Written by: Codex · Last updated: 2026-08-07
> Status: agreed by implementation request
> Upstream: docs/superforge.md

## 決定

- 再整列の対象は、AI Window Deck が「起動」で作成したウィンドウだけに限定する。設定画面、Dock、その他の通常Chromeウィンドウは対象外とする。
- 拡張自身のページは「現在立ち上がっている画面」からも除外する。
- 現在立ち上がっている画面は、タブグループ名が存在する場合、それをコンテキスト名として表示する。なければアクティブタブのタイトルを表示する。
- 登録済みウィンドウをキャンバスへドロップする場合、URLが空のスロットだけをドロップ先にする。対象スロットは青くハイライトされ、ドロップで名前・全URL・色を置換する。スロット数や分割は増やさない。
- 空きスロット以外、またはキャンバスの余白にドロップした場合は追加しない。ユーザーに空き枠を指定するよう伝える。
- Spotlight設定には、選択ディスプレイの実アスペクト比と現在キャンバスにあるスロットの配置を背景にしたプレビューを表示する。選択サイズ・アンカーの変更は、対象枠が拡大・移動するアニメーションで示す。

## 例外

- 一度起動したウィンドウが閉じられた場合は、再整列時に無視する。
- まだDeckから起動したウィンドウがないとき、再整列は何も作成しない。
- タブグループがない通常ウィンドウは、現在のアクティブタブ名で表示する。
