Overview

Your projects, side by side.

Ordinary Chrome windows for your cloud work. Keep sessions visible across projects and displays, then give the active window more room when you need it.

How it works

Four steps. A workspace that stays yours.

Follow the ①–④ stepper once. Return to any step when your projects change.

① Register URLs

Save a name and URLs for each window, or paste a list of sites to create several at once. Each URL opens as a tab.

② Layout

Place windows on the canvas and resize their grid slots.

③ Focus view

Choose an enlargement size and origin: grow in place or center.

④ Launch

Choose your displays and open the saved layout as Chrome windows.

New in 1.11.2

Paste a list. Get your windows.

Register URLs + Window opens right in the page. Add windows one by one, or paste a message that lists your sites: each block separated by a blank line becomes a window.

One by one, or all at once

Choose how to register. The bulk card shows a list being copied from a chat and pasted in.

Red lines, with a fix

Lines that need attention turn red. Each issue links to its line, and Fix adds the missing blank line for you.

https:// added for you

Type github.com and it is saved as https://github.com. localhost and local addresses get http://.

Local files

Paths such as /Users/me/My Site/index.html or C:\docs\notes.html open as file:// tabs, spaces included. Chrome opens them once Allow access to file URLs is on for the extension.

Several URLs on a line

URLs separated by spaces on one line each become a tab. Lines starting with a label like Memo: stay window names.

Focus view

Make room. Keep your place.

⌥X / Alt+X enlarges the active window. Grow in place to keep its position, or center it on the display. After a manual resize, ⌥Z / Alt+Z restores the window to its registered grid slot.

Multiple displays

Choose one or more displays for your workspace.

Backup and restore

Save windows, layouts and settings as JSON to take them to another machine.

06Privacy

It arranges windows. That is all it does.

No server, no account, no analytics. Your windows and layouts stay in your Chrome profile.

  • No host permissions and no content scripts. It does not read page content.
  • No network requests and no remote code.
  • No analytics, no advertising, no accounts.
  • Settings live in chrome.storage.sync, so Chrome can sync them between your own devices if Chrome Sync is on.
  • Undo state is kept in chrome.storage.session and cleared when the browser session ends.
  • Nothing is sent to the developer or to third parties.

07FAQ

Frequently asked questions

Which AI tools does it work with?
Any site you can open in Chrome. A saved window is just a name and a list of URLs, so chat assistants, documentation, notes and dashboards all work the same way.
Will it change my sign-ins or Chrome profile?
No. It opens ordinary Chrome windows in your current profile. Sign-ins, your password manager and other extensions behave as they always do.
Is any of my data sent anywhere?
No. The extension makes no network requests of its own. If Chrome Sync is on, Chrome may sync your settings between your own browsers. That is done by Chrome, not by the developer.
Why are some shortcuts not set?
Chrome allows an extension to suggest only four default shortcuts. Assign the rest at chrome://extensions/shortcuts.
Does it work across several monitors?
Yes. Choose one or more target displays before launching. The deck reads display sizes and positions to tile each window on the right one.
Can I move my setup to another computer?
Yes. Use Backup to save everything as a JSON file, then restore it on the other machine. With Chrome Sync on, settings may also follow you.
Where do I install it?
From the Chrome Web Store, or from a release ZIP.
