# AI Window Deck — Japanese localized screenshots

Upload these images in the Japanese (`ja`) localization section of the Chrome Web Store listing.

1. `screenshots/01-arrange.png` — AIのウィンドウをキャンバスで配置し、まとめて起動。
2. `screenshots/02-spotlight.png` — Alt+X で拡大、Alt+Z で元のタイルへ。
3. `screenshots/03-window-library.png` — 登録済みウィンドウと、いま開いているウィンドウの一覧。
4. `screenshots/04-register.png` — 1件ずつ、またはテキストでまとめて登録。
5. `screenshots/05-popup.png` — ツールバーのポップアップ。8言語対応。

All five PNGs are `1280 × 800`, opaque RGB, and show the Japanese interface of version `1.7.0`.
Regenerate with `store-assets/capture-store-assets.mjs` (see the header of that file).
