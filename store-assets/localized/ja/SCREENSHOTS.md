# AI Window Deck — Japanese localized screenshots

Upload these images in the Japanese (`ja`) localization section of the Chrome Web Store listing.

1. `screenshots/01-arrange.png` — Choose a display, arrange windows, and open a saved workspace.
2. `screenshots/02-spotlight.png` — Choose how the active window expands and where it lands.
3. `screenshots/03-window-list.png` — View and jump to the Chrome windows that are currently open.

All three PNG files are `1280 × 800` and show the current Japanese interface for version `1.6.0`.
