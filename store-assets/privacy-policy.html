Privacy Policy for AI Window Deck

Effective date: August 2, 2026

AI Window Deck is a Chrome extension that arranges Chrome windows and opens user-configured window sets. This policy explains the extension’s handling of data.

Information the extension handles

The extension handles only the information necessary for its user-facing features:

  • User-configured window sets and preferences. Names, URLs entered by the user, layout settings, display preferences, and language preferences are stored through Chrome’s storage service so that the extension can reopen and arrange the user’s windows.
  • Current Chrome window and tab metadata. The extension reads window bounds, window state, active tab title, URL, tab count, and tab-group information to arrange windows, show the window list, save a current setup, and focus or close a window when the user asks.

How information is used

Information is used only to provide the extension’s disclosed features: opening and arranging Chrome windows, restoring a previous layout, showing open windows, and grouping tabs.

Storage and retention

Preferences and saved window sets are stored in Chrome’s synchronized extension storage, which may synchronize them between Chrome browsers signed in to the same Google account. Temporary undo state is stored in Chrome’s session storage and is cleared according to Chrome’s session-storage lifecycle. The extension has no developer-operated server and does not send this information to a developer-operated server.

Sharing and sale

AI Window Deck does not sell, rent, transfer, or share user data with third parties. It does not use user data for advertising, retargeting, profiling, or creditworthiness or lending purposes. No person working for the publisher can access users’ extension data through the extension.

Permissions and website access

The extension requests access to Chrome tabs, windows, tab groups, display information, and storage because those capabilities are required to arrange and manage the user’s workspace. It does not run code on websites or request broad website access.

Your choices

You can edit or delete saved window sets in the extension. Removing the extension removes its locally stored extension data; any synchronized data is handled according to Chrome and Google Account settings.

Changes to this policy

If this policy changes, the effective date above will be updated and the revised policy will be published at this URL.

Contact

For privacy questions and support, open an issue at AI Window Deck Support.

This extension’s use and transfer of information received from Google APIs, if any, adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
